Will be: blog/posts/your-slug/

Supports HTML tags like <h2>, <p>, <ul>, <img>, etc.

Instructions: Upload images to blog/assets/images/ folder in your repo, then reference them as: <img src="../../assets/images/filename.jpg" alt="description">

How to Publish

Option 1: Publish Directly (Recommended)

  1. Fill in the form and click "Generate Post"
  2. Click "Preview" to review
  3. Click "Publish Directly" and select your blog/posts/ folder
  4. The post will be created and added to your blog automatically!
  5. Commit and push to GitHub

Option 2: Download Files (Manual)

  1. Fill in the form and click "Generate Post"
  2. Click "Preview" to review
  3. Click "Download Post Files" to get the HTML file
  4. Manually create folder blog/posts/{slug}/ and add the file
  5. Update blog/index.html to add a teaser for your new post
  6. Commit and push to GitHub

Quick tip: After uploading files to your repo, the homepage will automatically show your latest post!
